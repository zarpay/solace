# Curve25519

`Solace::Utils::Curve25519Dalek` provides native curve25519 operations via FFI. It loads a pre-compiled Rust shared library that ships with the gem.

## On-curve check

The primary operation is checking whether a 32-byte point lies on the Ed25519 curve. This is used during PDA derivation — a valid PDA must be **off-curve**.

```ruby
on_curve = Solace::Utils::Curve25519Dalek.on_curve?(32_byte_point)
```

Returns `true` if the point is a valid Ed25519 public key, `false` otherwise.

## Platform support

The gem ships pre-compiled binaries for:

| Platform | Library |
| --- | --- |
| Linux x86_64 | `libcurve25519_dalek.so` |
| Linux ARM64 | `libcurve25519_dalek.so` |
| macOS x86_64 | `libcurve25519_dalek.dylib` |
| macOS ARM64 | `libcurve25519_dalek.dylib` |
| Windows x86_64 | `curve25519_dalek.dll` |

The correct binary is selected automatically at runtime based on `RUBY_PLATFORM`.

## Building from source

If you need to compile the library yourself (for an unsupported platform or for development):

```bash
cd gem/ext/curve25519_dalek
cargo build --release
```

The compiled library will be in `target/release/`. Copy it to the appropriate directory under `gem/lib/solace/utils/`.
